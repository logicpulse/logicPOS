# Casa de cada peça privada

## Question

Entre os repositórios privados que já existem, qual é o anfitrião da edição LogicPulse?

## Note

O opensource fica só no `logicPOS`. API, cliente, cloud, fiscal, migradores, web e instalador ficam juntos em `logicPOS-internal`. O SVN antigo fica de fora.

## Answer

O anfitrião da edição LogicPulse fica em `logicPOS-internal`, com a API, o cliente, a cloud, o fiscal, os migradores, a web e o instalador. O opensource fica só no `logicPOS`. O SVN antigo fica de fora.
