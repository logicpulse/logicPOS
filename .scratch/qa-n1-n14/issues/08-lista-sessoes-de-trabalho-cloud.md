# A lista cloud de Sessões de Trab. mostra o período ou só terminais abertos?

Type: grilling
Status: resolved

## Question

Na base cloud, a lista «Sessões de Trab.» deve mostrar as sessões do período filtrado, incluindo as fechadas, ou só as sessões de terminal que estão abertas?

## Decision

A lista mostra só as sessões abertas. As fechadas não entram.
