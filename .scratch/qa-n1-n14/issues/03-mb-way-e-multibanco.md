# MB Way substituiu o Multibanco ou são dois métodos?

Type: grilling
Status: resolved

## Question

Com o código interno «MB», MB Way e Multibanco são o mesmo método com o nome novo, ou são dois métodos distintos no FrontOffice e no BackOffice, em base nova e em base já criada?

## Decision

São dois métodos. MB Way só aparece quando a base é de Portugal (pt-PT). Multibanco não é o nome novo do MB Way.
