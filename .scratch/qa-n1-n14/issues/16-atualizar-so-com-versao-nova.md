# 16: Atualizar só com versão nova

**What to build:** Sistema → Atualizar só pergunta «Descarregar a atualização e reiniciar?» quando já se sabe que há uma versão mais nova, e a pergunta diz qual é. Sem versão mais nova, não há pergunta. O que conta como mais nova é a comparação de versões que já existe.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Sem versão mais nova, não aparece a pergunta de descarregar e reiniciar
- [x] Com versão mais nova, a pergunta inclui essa versão
- [x] A comparação de versões já existente não é redefinida
- [x] Um facto novo cobre a pergunta, sem repetir os factos da comparação
